# Проверка ДЗ — Автоматизация выгрузки непроверенных работ

Скрипт для автоматической выгрузки непроверенных работ студентов Нетологии
с учётом производственного календаря РФ, SLA и дней недели.

## 📁 Структура проекта

```
├── input/                          ← 📥 Входные файлы
├── output/                         ← 📤 Результаты работы
├── data/                           ← ⚙️ Конфигурационные данные (JSON)
│   ├── calendar.json               ← 📅 Праздники и рабочие субботы
│   └── modules.json                ← 📚 Списки модулей
│
├── gui_config_editor.py           ← 🆕 GUI-редактор конфигов
├── config.py                       ← 🔧 Пути, SLA, фильтры БЮ
├── calendar_module.py              ← 📅 Логика производственного календаря
├── processor.py                    ← 🔄 Загрузка и обработка данных
├── exporter.py                     ← 💾 Экспорт в Excel/TXT
├── main.py                         ← 🚀 Точка входа
│
├── tests/                          ← 🧪 Юнит-тесты
│   ├── __init__.py
│   ├── test_calendar.py
│   ├── test_processor.py
│   └── test_exporter.py
│
├── requirements.txt                ← 📦 Зависимости
└── README.md                       ← 📖 Документация
```

## 🚀 Быстрый старт

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Поместите файл в папку input/
cp Непроверенные_работы.xlsx input/

# 3. Запустите
python main.py
```

Папки `input/`, `output/`, `data/` создаются автоматически (кроме `data/` — её нужно создать вручную и положить JSON).

## 📅 Расписание выгрузок

| День недели | Что выгружается |
|-------------|-----------------|
| Пн, Ср, Пт  | ДЗ (≥2 раб. дня), Дипломы |
| Чт          | Курсовые (≥5 раб. дней) |

## 📚 Обновление списков модулей

При добавлении нового модуля:
1. Откройте `data/modules.json`
2. Добавьте модуль в нужный массив:
   - `diploma_modules` — дипломные работы
   - `self_assignment_modules` — модули с самостоятельным назначением
3. Сохраните файл и перезапустите скрипт

**Не нужно трогать Python-код!**

## 📅 Обновление календаря

Каждый год в январе (после публикации постановления Правительства РФ):
1. Откройте `data/calendar.json`
2. Добавьте новые праздники в массив `holidays`
3. Добавьте рабочие субботы в массив `extra_days`

Формат даты: `YYYY-MM-DD` (ISO).

## 🧪 Запуск тестов

```bash
pytest tests/ -v
```

## ⚙️ Настройки

Все настройки в `config.py`:
- `SLA_DZ_DAYS = 2` — SLA для ДЗ
- `SLA_KURS_DAYS = 5` — SLA для курсовых
- `CHECK_DAYS_DZ_DIPLOMA = {0, 2, 4}` — дни выгрузки ДЗ/Дипломов
- `CHECK_DAYS_KURS = {3}` — дни выгрузки курсовых

## 🛠 Редактор конфигурации (GUI)

Для удобного редактирования JSON-файлов запустите:

```bash
python gui_config_editor.py
```

Приложение позволяет:
- 📅 Управлять календарём праздников и рабочих суббот
- 📚 Добавлять/удалять модули с живым поиском
- 💾 Сохранять изменения одной кнопкой (Ctrl+S)

**Горячие клавиши:**
- `Ctrl+S` — сохранить всё
- `Delete` — удалить выбранную строку
- Двойной клик — редактировать
